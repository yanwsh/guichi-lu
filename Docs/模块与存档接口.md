# 模块与存档接口草图 v0.1

对齐：`docs/01-策划/灰盒剧本配置节奏.md`（场景 ID、对白 ID、遭遇表、抉择 flag、连携解锁）。  
依赖单向：`Flow → Scene / Dialog / Battle → Data`；`Save` 只序列化 **GameState**，不引用表现层。

## 共享状态 `GameState`（存档主体）

```csharp
// 逻辑草图 — 正式代码进 Guichi.Save / Guichi.Data
public sealed class GameState {
  public string FlowNodeId;           // 当前章节流程节点
  public string SceneId;              // 当前场景
  public Dictionary<string, int> Flags; // 抉择 / 连携等
  public List<string> PartyIds;
  public BattleResume? Battle;        // null=不在战斗；非空=可恢复或回退战前
  public int SaveVersion;
}

public sealed class BattleResume {
  public string EncounterId;
  public string PreBattleSnapshotId;  // 指向战前 GameState 快照槽
}
```

- **任意时刻存档** = 序列化当前 `GameState`（不含战斗表现）。
- **战斗中断** = 至少能回退到战前快照（`PreBattleSnapshotId`）；灰盒可不做战斗中途精确恢复。

## Flow

```csharp
public interface IFlowController {
```

## Dialog（与苏禾剧本字段对齐前置）

```csharp
public interface IDialogRunner {
  void Play(string dialogueId);            // 从表 dialogues 起播
  void Advance();                          // 快进单句
  void Choose(string choiceId);            // 选项 → Flow.OnChoice
  void SkipToEndOfNode();                  // 可选
}

// 对白行（配置 / Yarn 落地前的表结构）
public sealed class DialogueLine {
  public string DialogueId;
  public string SpeakerId;                 // character_id 或旁白
  public string Text;
  public string PortraitKey;               // W0 立绘
  public string NextDialogueId;            // 空则结束节点
  public string[] ChoiceIds;               // 非空则出抉择 UI
}
```

灰盒可用 **表格剧本**（上表）先跑通；Yarn Spinner 作为 W2 候选，导出或手写须仍能落到 `dialogue_id` / `choice_id` / `flag_id`。

## Battle

```csharp
public interface IBattleLogic {            // 纯 C#，可单测

public interface IBattlePresenter {
  void Bind(IBattleLogic logic);

```

连携：开战前读 `Flags[unlock_flag]`；`links` 表定义参与者与次数。

## 存档 IO

```csharp
public interface ISaveService {
  void WriteSlot(int slot, GameState state);
  GameState ReadSlot(int slot);
  void WriteSnapshot(string snapshotId, GameState state);
  GameState ReadSnapshot(string snapshotId);
}
```

格式：JSON 文件（`persistentDataPath/saves/`）即可；`SaveVersion` 做迁移钩子。

## 与策划联调检查单

- [ ] 场景切换只认 `scene_id`（取值与 W0 同名：`SC_01_OPEN`…`SC_05_BOSS`）
- [ ] 对白/抉择只认 `dialogue_id` / `choice_id` / `flag_id`
- [ ] 遭遇只认 `encounter_id`
- [ ] 连携解锁只认 flag（如 `link_tongxin_unlocked`）
- [ ] 三线（主线 / 救人 / 追凶）差异只通过 flag + 表跳转表达
