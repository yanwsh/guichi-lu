# SC_03 可走桩（M1）

单屏山门驿亭。触发坐标只认 `public/config/walkmaps/SC_03_TOWN.json`（苏禾 v0.3.x，原点左上、y 向下、1080×1920）。手绘分层 v0.3 在 `public/assets/walkmaps/SC_03_TOWN/`。

## 怎么进

```bash
npm install
npm run dev
```

标题 **SC_03 可走桩** 跳过开场，直接站在 N3。正式串法仍是开始游戏 → 开场 → 岔口 → 下一场景，到 `SC_03_TOWN` 时改走可走场景，不再铺全屏插画。

## 操作

- 点石径：射线落到画面，再 A*。人沿折线连续走，不是一格一顿。
- 左下摇杆：设计包安全区（表内 `safe_ui.joystick`，约 x0–280、y1620–1920）。
- 右下按钮：走近「调查爪痕 / 香案 / 进镇」才出现。
- 对白和战斗时停步。底栏底边约在 y=1600，立绘叠在场景上，画面不卸空。
- 调查之后才开 N3→N4。走进石坪触发 `ENC_TUTORIAL_01`。败了停在圈外，再走进去重试。胜后可上 N5。

## 不在本轮

- 不改触发表坐标，不改 walkable 形状，不加迷宫或岔环假道。
- `paths[].waypoints` 只是预留字段，寻路仍只用蒙版格子。
- 蒙版可换：替换同尺寸 `SC_03_TOWN_walkable.png`，或 `WalkScene.reloadWalkable(url)`。本 PR 不另做一套障碍。
- 长卷 1080×3600 未进运行时。换算 `y_scroll = y_single + 1680`，初始 scrollY=1680 才与单屏重合；北段暂不可走。见 `docs/03-美术/场景/SC_03_walkmap_scroll/README.md`。
- 存档 `save_version` 为 2，多了 `walk_pos` 与 `triggered_ids`。旧 v1 档会升上来，没有场景内坐标。
