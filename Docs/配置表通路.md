# 配置表通路草案 v0.1

对齐策划侧：`docs/01-策划/灰盒剧本配置节奏.md`（场景 ID、对白 ID、遭遇表、抉择 flag、连携解锁）。

## 结论

- **目标通路**：Excel（或 CSV）→ **Luban** → 强类型 C#（`Guichi.Data`）+ 只读运行时表
- **W1 临时通路**：手写 / 导出 **JSON** 放 `Config/Samples/`，运行时用同构 DTO 读取；目录与字段名与 Luban 目标对齐，避免二次改名
- 策划改表后经 CI 或本机导出脚本校验；灰盒阶段允许程序协助打进包

## 目录约定

```
guichi-lu/
  Config/
    Tables/           # 策划源表（.xlsx / .csv），Git 跟踪
    Samples/          # W1 临时 JSON，字段与目标 C# DTO 一致
    Generated/        # Luban 生成物（可 Git 忽略或提交；团队择一）
  Docs/
    配置表通路.md     # 本文
  Assets/Scripts/Data/  # 运行时加载与表访问（asmdef: Guichi.Data）
```

公司资料库中的设计权威仍在 `docs/`；本仓库 `Config/` 只放**可导入游戏的数据**。

## 建议表清单（灰盒最小集）

| 表名 | 主键 | 用途 | 对应策划接口 |
|------|------|------|--------------|
| `scenes` | `scene_id` | 场景名、底板资源、可交互点列表 | 场景 ID |
| `dialogues` | `dialogue_id` | 对白行、说话人、立绘、下一句/选项 | 对白 ID |
| `choices` | `choice_id` | 选项文案、写 flag、跳转 | 抉择 flag |
| `flags` | `flag_id` | 默认值、说明（文档用） | 抉择 / 连携 |
| `encounters` | `encounter_id` | 敌编成、是否教学/Boss、胜利跳转 | 遭遇表 |
| `enemies` | `enemy_id` | 属性、技能、五行 | 战斗 |
| `characters` | `character_id` | 我方属性、技能、立绘 key | 角色 |
| `skills` | `skill_id` | 消耗、目标、五行、演出 key | 战斗 |
| `links` | `link_id` | 连携参与者、解锁 flag、效果 | 连携解锁条件 |


## 场景 ID 命名（与美术 W0 对齐）

`scene_id` **必须**与 W0 底板文件名主干一致（去掉 `_v0` 等后缀）：

| scene_id | W0 文件 |
|----------|---------|
| `SC_01_OPEN` | `SC_01_OPEN_v0.png` |
| `SC_02_MEET_A` | `SC_02_MEET_A_v0.png` |
| `SC_03_TOWN` | `SC_03_TOWN_v0.png` |
| `SC_04_CHOICE` | `SC_04_CHOICE_v0.png` |
| `SC_05_BOSS` | `SC_05_BOSS_v0.png` |

`bg_key` 建议：`W0/scenes/{scene_id}`。禁止再用短写 `SC_01`。

## 临时 JSON 样例

见 `Config/Samples/`。字段用 `snake_case` 与表头一致；C# 侧可用 `[JsonPropertyName]` 或生成代码映射。

## Luban 落地（有 Editor / CI 后）

1. 将 `Config/Tables/` 作为 Luban 输入
2. 输出到 `Config/Generated/` 与 `Assets/Scripts/Data/Generated/`
3. 运行时只读 `Tables` 单例，禁止玩法模块直接改表数据
4. CI：表校验失败则阻断夜间包

## 明确不做（M2 前）

- 热更配表下发
- 运行时写回 Excel

## Web 加载路径（Three.js，v0.2）
- 源：`Config/Samples/{scenes,dialogues,encounters,flags,links}.json`；改后拷到 `public/config/`（运行时 `fetch(import.meta.env.BASE_URL + "config/<表>.json")`，见 `src/data/loader.ts`）
- 类型：`src/data/types.ts`，字段 snake_case 与样例一致
- `scenes` 新增可选：`next_scene_id`、`interact_encounters`（interactable_id → encounter_id）
- `dialogues`：`dialogue_id`、`lines[{speaker,portrait_key,text}]`、`choices[{choice_id,text,set_flag,value}]`
- `bg_key` 解析：`<bg_key>_v0.png`，位于 `public/W0/scenes/`

- 对白扩展字段：`next_dialogue_id`（同场景连播）、`choices[].followup_lines`（分支旁白）、`start_encounter_id`（对白结束开战）。
