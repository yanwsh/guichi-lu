## 说明 / 限制
- 北段石径（y 0–2115）v0.3 **为视觉延展，暂不可走**（被驿亭挡住）；若要 N5→N6 北出口可走，需开卡后改亭台通路 + 扩 walkable。
- 相机：长卷底对齐单屏，镜头初始 scrollY=1680 时画面与单屏完全一致。

本目录只收换算备忘。本轮附件没有 *_scroll.png 二进制；M1 运行时仍用单屏 1080×1920，不切长卷相机。
